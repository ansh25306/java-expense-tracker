---

## 2. Problem Statement

Managing personal expenses is an important part of financial planning. Students and individuals often spend money on food, transportation, education, shopping, entertainment, and other daily activities without maintaining proper records.

Without a proper system for tracking expenses, it can become difficult to understand spending habits, control unnecessary expenses, and stay within a monthly budget.

The **Java-Expense-Tracker** project provides a simple console-based solution for recording and managing financial transactions. It allows users to track expenses, manage income and budgets, and generate reports that provide a clear overview of their spending.

---

## 3. Proposed Solution

Expense Controller is a Java-based personal expense management application.

The system provides a menu-driven interface through which users can:

* Add new expenses.
* View recorded expenses.
* Update expense information.
* Delete expenses.
* Add or update monthly income.
* Set a monthly spending budget.
* Calculate total expenses.
* Calculate remaining balance.
* Calculate remaining budget.
* Analyze category-wise spending.
* Identify the highest spending category.
* Save and load expense data using local text files.

The application uses Object-Oriented Programming and modular design to separate different responsibilities of the system.

## 7. Major Modules

### Expense Management

This module handles the complete lifecycle of expense records, including adding, viewing, updating, and deleting expenses.

### Income and Budget Management

This module manages the user's monthly income and spending budget and calculates the remaining balance and budget.

### Expense Reports

This module calculates total expenses, category-wise spending, highest spending category, and overall financial summaries.

### Data Storage

This module saves expense and settings information into local text files and loads the data when the application starts.

### Input Validation

This module checks user inputs and prevents invalid values such as negative expenses, empty fields, invalid numbers, and incorrect menu selections.
