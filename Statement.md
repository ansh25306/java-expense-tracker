## 1. Project Title

**Java Expense Tracker**

---

## 2. Problem Statement

Managing daily expenses manually can be difficult for students and individuals. People may spend money on food, transportation, shopping, education, and other activities without keeping a proper record.

Without tracking expenses, it becomes difficult to know how much money has been spent, where the money is being spent, and whether the monthly budget is being exceeded.

The **Java Expense Tracker** provides a simple console-based solution for recording and managing daily expenses.

---

## 3. Proposed Solution

The Java Expense Tracker is a console-based application developed using Java.

The application allows users to:

* Add new expenses.
* View all recorded expenses.
* Calculate total expenses.
* Search expenses by category.
* View category-wise expense summaries.
* Calculate monthly expenses.
* Set a monthly budget.
* Check budget status.
* Receive a warning when the budget is exceeded.
* Delete existing expenses.

The project provides a simple way to organize and analyze personal spending.

---

## 4. Objectives

The main objectives of this project are:

1. To maintain records of daily expenses.

## 7. Major Features

### Add Expenses

Users can enter details of their expenses and store them in the application.

### View Expenses

Users can view all the expenses that have been recorded.

### Total Expenses

The application calculates and displays the total amount spent.

### Search by Category

Users can search for expenses belonging to a particular category such as Food, Transport, Shopping, or Education.

### Category-wise Summary

The application provides a summary of expenses based on different categories.

### Monthly Expense Calculation

Users can calculate their expenses for a particular month.

### Monthly Budget

Users can set a monthly spending budget and compare their expenses against it.

### Budget Warning

The application displays a warning when the total expenses exceed the set monthly budget.

### Delete Expenses

Users can delete an existing expense from the expense list.
